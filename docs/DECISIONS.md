# Decisions Log

Newest at the bottom. Each entry: what was decided, why, and whether it can still change.

## D1. Rebuild from scratch on a branch
The first build is preserved unchanged on the `legacy-v1` branch (and on `main` until the rebuild
is merged). The rebuild lives on `rebuild`; features branch off it as `feat/<name>`. A git tag was
the first choice for the archive, but tag pushes are blocked from the build environment, so a
branch is used instead.

## D2. Stack
- Mobile: Expo SDK 57 (latest stable in October 2026), React Native, TypeScript, expo-router.
- Backend: Node 22, Express 5, TypeScript as ES modules, Zod for validation, pino for logs,
  Vitest and Supertest for tests.
- Database: PostgreSQL 16 in Docker locally and on the Oracle server. The ORM is chosen in Phase 1
  when the first table arrives; the default is Prisma 7 with the pg adapter, the setup that worked
  in `legacy-v1`.
Reason: this is the stack Peter chose in the interview. Changeable only with a logged decision.

## D3. Version 1 scope
Launch scope is fixed in `docs/SPEC.md` section 4; section 5 lists what waits for v2. Peter
confirmed the proposed cut by starting the build.

## D4. No borrowed code or assets
openGym is AGPL-3.0, so it is used for ideas only; see `docs/REFERENCE.md`. Exercise text and
metadata come from free-exercise-db (Unlicense). Its images are not used because their license is
not stated. Exercise images are generated by Peter in batches and owned by ProFit.

## D5. Theme
Sandstone palette, dark by default with a light toggle. The dark variant was designed for the
rebuild, and the light terracotta was deepened slightly to meet text contrast. Details in
`docs/DESIGN.md`.

## D6. App identifiers
- Expo slug `profit` and the existing EAS project id are kept so builds stay linked to the same
  EAS project.
- Android package and iOS bundle id are `com.quanticengineering.profit`, under Peter's company
  instead of the first build's `com.mundala.profit`. This can change freely until the first upload
  to Google Play, after which it is permanent.
