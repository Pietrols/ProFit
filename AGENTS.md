# AGENTS.md

Instructions for coding agents (Codex and others) working on ProFit.

1. Read `CLAUDE.md` (project rules; they apply to every agent, not only Claude).
2. Then follow `docs/BUILD_PLAN.md`: it is the source of truth for what to build next and how.
   Work on the first unticked step, tick it in the commit that completes it, and stop for Peter's
   review at the end of each phase.
3. Mobile code: also read `mobile/AGENTS.md` before touching Expo APIs.
4. Never use em dashes in anything you write.
